NSF ChemMatCARS · Argonne National Lab & UChicago · 2024–2026

A sessile drop method for XModFit

I built Python image-analysis tools that pull quantitative measurements out of experimental images for synchrotron materials research, including droplet profiles, X-ray scattering and tensiometry. For XModFit, a scientific analysis platform, I developed a generalized sessile drop profile method. It finds the droplet’s edge with polar-coordinate interpolation, then uses Young–Laplace fitting to model the drop and its surface tension.

Python · OpenCV · NumPy · Technical documentation
